This is an entry point to Career Wayfinder. The guide's engine lives in the sibling skill folder `career-wayfinder` (next to this skill's base directory).

1. Read `<this skill's base directory>/../career-wayfinder/SKILL.md` for the ground rules, the tools and the session shape. Set `S` to `<this skill's base directory>/../career-wayfinder/scripts/wayfinder.py` and find `WS` as it describes.
